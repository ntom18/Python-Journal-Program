# Python Journal Project

## Overview
This is a Python program I created to apply what I've learned in class and outside study. The program lets users write, view, and search daily journal entries with custom mood tracking.

## What This Program Does
- Write and save new daily journal entries with custom text and mood tracking
- View stored journal records from text files
- Search through entries to find specific logs

## Skills Used
- File I/O operations
- Functions
- Loops
- Conditional statements
- Basic error handling
